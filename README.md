# Template engines

Nift as a template engine, independently of tracked builds and whole-site generation. Five engines: Nift embedded C++, Jinja2, Nunjucks, Handlebars, LiquidJS. Canonical evidence is published in nift-experiments/lab-evidence; Labs receives compact summary statistics and displayed charts only.

See docs/METHODOLOGY.md. No Nift core modifications are authorized. Local correctness and feasibility precede one fresh inexpensive cloud host. Accepted campaigns elsewhere remain frozen.
